# Pokémon Cristal Nuzlocke — Tito Xeluis v4.2

Modificación personal de Pokémon Cristal para Game Boy Color, basada en el código fuente español de MicaelAlighieri/pokecristal y el trabajo de la comunidad pret/pokecrystal. No es un producto oficial de Pokémon.

## Descarga

Un único archivo jugable: **`Pokemon Cristal Nuzlocke.gbc`** (ROM normal v4.2).

- SHA-256: `fc8fd409da5c20f5e7e17f1b0aef34d970f3a61e0fdeb518a41011c966d337f4`
- No necesita ROM base ni aplicar parches. Ábrela con un emulador compatible con Game Boy Color (se obtiene por separado). El modo ×2 depende de las opciones del emulador.
- Las actualizaciones de esta familia continúan el guardado interno del juego; no uses estados rápidos de otra compilación. Otra semilla del randomizador requiere partida nueva.

Los archivos «Source code» que GitHub genera automáticamente no son la descarga para jugar.

## Novedades de 4.2

1. **Sprite de Tito:** arte nativo de 16×16 revisado, tres poses y fotogramas alternos completos; la derecha se refleja por hardware.
2. **Ulex:** espacio de gráficos propio en mapas exteriores; el disfraz y la revelación como recluta Rocket se comprobaron en las 16 rutas.
3. **Sandbox:** OBJETOS ya no se bloquea (llamada entre bancos de ROM corregida).
