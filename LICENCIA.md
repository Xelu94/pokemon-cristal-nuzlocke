# Licencia: decisión pendiente

**No se ha asignado ninguna licencia a este repositorio.** Mientras no exista un archivo de licencia, GitHub considera que se reservan todos los derechos sobre el contenido propio.

## Qué hay que decidir

El autor debe decidir qué licencia aplicar **solo a sus aportaciones propias**:

- Documentación y textos del repositorio.
- Randomizador portable y scripts de pruebas y herramientas.
- Sprites y retrato de Tito Xeluis y demás recursos propios.
- El contenido del parche en lo que sea creación original (no el código base).

## Qué no se puede relicenciar

- El código y los recursos heredados de [MicaelAlighieri/pokecristal](https://github.com/MicaelAlighieri/pokecristal) y [pret/pokecrystal](https://github.com/pret/pokecrystal), incluidas las partes de ese código que el parche modifica.
- Los personajes, nombres y contenidos de Pokémon, que pertenecen a sus titulares.
- Las herramientas externas, que mantienen su licencia.

Antes de elegir una licencia para las aportaciones propias conviene revisar las condiciones de las bases citadas. Esta decisión no se toma aquí ni se implica en el resto de documentos.
